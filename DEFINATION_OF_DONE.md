# Definition of Done

A task is done when:

- [ ] Requirement/acceptance criteria are satisfied
- [ ] Relevant code is implemented
- [ ] Type-check passes
- [ ] Lint passes
- [ ] Relevant tests pass
- [ ] Security impact reviewed
- [ ] Database impact reviewed when applicable
- [ ] Relevant manual validation completed
- [ ] Documentation/project state updated when necessary
- [ ] No known critical blocker remains
